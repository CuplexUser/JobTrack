JobTrack Clipper

The token is generated by JobTrack on first run and lives in data/api-token inside its data directory — on Windows that is %APPDATA%\jobtrack\data\api-token. It is what lets this extension in; pages you merely visit have no way to get one.

The tray app and a standalone jobtrack install listen on 3001. npm run dev puts the API on 3002 instead, so point this there when testing against a dev server.
