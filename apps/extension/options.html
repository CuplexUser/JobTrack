JobTrack Clipper

Saves the job posting you are reading into JobTrack on this computer. Connect once and you are set.

The Windows app and a standalone jobtrack install listen on 3001. npm run dev puts the API on 3002 instead, so point this there when testing against a dev server.

Opens a JobTrack page in a new tab. Press Allow there and this page does the rest.

Enter the token by hand

For a JobTrack older than 1.3.0, or when connecting does not work. The token is in data/api-token inside JobTrack's data folder, which on Windows is %APPDATA%\jobtrack\data\api-token. The Windows tray menu also has Copy API token.
